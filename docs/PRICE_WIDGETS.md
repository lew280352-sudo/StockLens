# ราคาของบริษัทที่ติดตาม

เมื่อไม่มี Finnhub key หน้า overview/following แสดง Market Data widget ของ TradingView ซึ่งมีข้อมูลพร้อมในตัวและไม่ต้องใช้คีย์ของแอป หุ้นมาจากรายการที่ติดตามในบัญชีและผ่านรายชื่อบริษัทที่แอปรองรับเท่านั้น ไม่เพิ่มหุ้นเริ่มต้นให้เอง รายการว่างไม่โหลดวิดเจ็ต

ข้อมูลของตลาดหุ้นสหรัฐฯ ในวิดเจ็ตมีความล่าช้า แอปแสดงสถานะนี้ พร้อมแหล่งข้อมูล ลิงก์หุ้นที่ผู้ให้บริการและ attribution/branding เดิมของ TradingView เวลา “เปิดตาราง” หมายถึงการเปิดวิดเจ็ต ไม่ใช่เวลาซื้อขายล่าสุด หากผู้ให้บริการหรือเครือข่ายปิดการแสดง iframe ยังเปิดลิงก์หุ้นโดยตรงได้

เมื่อมี Finnhub key ระบบ API/cache/เวลา/สถานะข้อมูลเก่ายังทำงานเหมือนเดิม หากไม่มีราคา API เลยจะแสดงตารางฟรี เมื่อมีราคาเพียงบางรายการยังแสดงค่าที่มีและเสนอปุ่มเปิดตารางฟรี ไม่แต่งราคามาแทนข้อมูลที่ขาด

## การแสดงและข้อมูลที่ส่ง

- ฝัง iframe ของ `https://www.tradingview-widget.com/embed-widget/market-quotes/` ด้วยการตั้งค่า Market Data รูปแบบเดียวกับตัวโหลดวิดเจ็ตทางการ
- ใช้ข้อมูลสำหรับแสดงให้ผู้ใช้อ่านใน iframe ของผู้ให้บริการเท่านั้น แอปไม่ scrape ราคา ไม่บันทึกข้อมูลวิดเจ็ตลงฐานข้อมูล ไม่ส่งเข้า AI และไม่ใช้เป็นข้อมูล backtest
- ค่าที่แอปใส่ในวิดเจ็ตมี ticker/ชื่อบริษัทจาก catalog, ธีม และ origin ของเว็บ ไม่มีชื่อ อีเมล คุกกี้ session หรือ API key ของบัญชี การเชื่อมต่อภายนอกมี IP ของเบราว์เซอร์และข้อมูลทางเครือข่ายตามปกติ
- คง `script-src 'self'` และ `connect-src 'self'` ของหน้าแอป เพิ่ม `frame-src` เฉพาะ origin ของวิดเจ็ต วิดเจ็ตเป็น cross-origin iframe มี sandbox และใช้ referrer policy แบบ origin
- ธีมและรายการหุ้นเปลี่ยนแล้วสร้างวิดเจ็ตใหม่ ปุ่มอัปเดตเปิดการเชื่อมต่อใหม่ ผล API ที่กลับมาหลัง logout ถูกละทิ้งและ iframe ถูกลบออกจากหน้าทันที

## การตรวจ

Playwright ตรวจบัญชีที่ไม่มีคีย์ รายการว่าง/หลายหุ้น ticker แบบ BRK.B ธีมมืด/สว่างที่ 390/768/1440px การอัปเดต ลิงก์เมื่อวิดเจ็ตไม่โหลด ราคาจาก API ที่ยังมีบางส่วน และผลที่กลับมาหลัง logout การตรวจใน CI ใช้ข้อมูล fixture ที่ระบุชัดเจน การตรวจวิดเจ็ตจริงแยกต่างหากในเบราว์เซอร์ พบราคาของ NVDA และหุ้นทั้ง 36 บริษัทที่ catalog รองรับ โดยไม่ตั้งคีย์

## เปรียบเทียบย้อนหลัง

กดเปิดการเปรียบเทียบแล้วเลือกหุ้นที่ติดตามและช่วงเวลาได้ 6 ช่วง: วันซื้อขายก่อน, สัปดาห์, 1/3/6 เดือน และ 1 ปี ใช้ Symbol Overview iframe ของ TradingView แบบ `changeMode=price-and-percent` โดยกำหนด `dateRanges` เพียงช่วงที่เลือก เพื่อให้ทั้งกราฟและส่วนต่าง USD/% ใช้ช่วงเดียวกัน ไม่อ่านตัวเลขจาก iframe กลับเข้าแอป API หรือ AI กราฟมีข้อมูลในตัว จึงไม่ต้องใช้ API ราคาย้อนหลังแบบ Premium ของ Finnhub

เวลา จุดราคา และการจัดการวันหยุดในกราฟเป็นไปตามผู้ให้บริการ ผู้ใช้แตะหรือชี้เส้นเพื่อดูวันที่/ราคาได้ ราคาอาจต่างจากตาราง Finnhub เนื่องจากแหล่งข้อมูลและความล่าช้าต่างกัน การเปลี่ยนเปอร์เซ็นต์ของกราฟไม่ใช่ผลตอบแทนพอร์ตของบัญชี

ตาราง Finnhub ใช้ `pc` ของคำตอบ quote เป็นราคาปิดก่อนหน้า และคำนวณ `change = c - pc`, `changePercent = (c - pc) / pc * 100` เฉพาะเมื่อข้อมูลเป็นจำนวนจริง ราคาปิดก่อนหน้าเป็นบวก และผลคำนวณเป็นจำนวนจำกัด ไม่สมมติวันที่ของราคาปิดที่ API ไม่ได้ส่งมา และไม่แสดงศูนย์แทนข้อมูลที่ขาด รุ่น cache เดิมที่ยังไม่มี `pc` จะเพิ่มข้อมูลนี้ตามรอบอัปเดตราคาปกติ

## แนวโน้มใน AI Insights

เมื่อ API ประวัติของแอปยังไม่มีข้อมูลที่ใช้ได้ หน้า AI Insights แสดงกราฟราคา 1 ปีและ Technical Analysis ของ TradingView โดยไม่ต้องตั้งคีย์เพิ่ม เลือกกรอบเวลาตัวชี้วัดรายวัน รายสัปดาห์ หรือรายเดือนได้ เริ่มที่รายสัปดาห์ ปุ่มอัปเดตแนวโน้มตรวจแหล่งข้อมูลและเปิดการเชื่อมต่อวิดเจ็ตใหม่

กราฟราคาใช้รายวันย้อนหลัง 1 ปี ส่วนกรอบเวลาในปุ่มใช้กับสัญญาณทางเทคนิคเท่านั้น ทั้งสองส่วนแสดงผลจากผู้ให้บริการโดยตรง ไม่อ่านค่าจาก iframe เข้า API/AI หรือ backtest คง branding/attribution และมีลิงก์เปิดข้อมูลต้นทาง ข้อมูลอาจล่าช้าและสัญญาณอาจเปลี่ยนขณะยังไม่จบแท่งราคา

สัญญาณ TradingView เป็นสรุปจากตัวชี้วัดของผู้ให้บริการ ไม่ใช่ผลทดสอบกฎสี่สัปดาห์ของแอป หากมีประวัติ Alpha Vantage ที่สดและครบตามเกณฑ์ ยังคงแสดงกราฟรายสัปดาห์และผลทดสอบเดิม การไม่มีข้อมูล ข้อมูลไม่พอ ข้อมูลเก่า หรือ API ผิดพลาดจะใช้ส่วน TradingView เพื่อให้ยังเปิดดูได้
