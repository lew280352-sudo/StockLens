# ราคาของบริษัทที่ติดตาม

เมื่อไม่มี Finnhub key หน้า overview/following แสดง Market Data widget ของ TradingView ซึ่งมีข้อมูลพร้อมในตัวและไม่ต้องใช้คีย์ของแอป หุ้นมาจากรายการที่ติดตามในบัญชีและผ่านรายชื่อบริษัทที่แอปรองรับเท่านั้น ไม่เพิ่มหุ้นเริ่มต้นให้เอง รายการว่างไม่โหลดวิดเจ็ต

ข้อมูลของตลาดหุ้นสหรัฐฯ ในวิดเจ็ตมีความล่าช้า แอปแสดงสถานะนี้ พร้อมแหล่งข้อมูล ลิงก์หุ้นที่ผู้ให้บริการและ attribution/branding เดิมของ TradingView เวลา “เปิดตาราง” หมายถึงการเปิดวิดเจ็ต ไม่ใช่เวลาซื้อขายล่าสุด หากผู้ให้บริการหรือเครือข่ายปิดการแสดง iframe ยังเปิดลิงก์หุ้นโดยตรงได้

เมื่อมี Finnhub key ระบบ API/cache/เวลา/สถานะข้อมูลเก่ายังทำงานเหมือนเดิม หากไม่มีราคา API เลยจะแสดงตารางฟรี เมื่อมีราคาเพียงบางรายการยังแสดงค่าที่มีและเสนอปุ่มเปิดตารางฟรี ไม่แต่งราคามาแทนข้อมูลที่ขาด

## การแสดงและข้อมูลที่ส่ง

- ฝัง iframe ของ `https://www.tradingview-widget.com/embed-widget/market-quotes/` ด้วยการตั้งค่า Market Data รูปแบบเดียวกับตัวโหลดวิดเจ็ตทางการ ไม่ใช้ Yahoo endpoint ที่ไม่ได้ให้สิทธิ์นำข้อมูลมาเผยแพร่ต่อ
- ใช้ข้อมูลสำหรับแสดงให้ผู้ใช้อ่านใน iframe ของผู้ให้บริการเท่านั้น แอปไม่ scrape ราคา ไม่บันทึกข้อมูลวิดเจ็ตลงฐานข้อมูล ไม่ส่งเข้า AI และไม่ใช้เป็นข้อมูล backtest
- ค่าที่แอปใส่ในวิดเจ็ตมี ticker/ชื่อบริษัทจาก catalog, ธีม และ origin ของเว็บ ไม่มีชื่อ อีเมล คุกกี้ session หรือ API key ของบัญชี การเชื่อมต่อภายนอกมี IP ของเบราว์เซอร์และข้อมูลทางเครือข่ายตามปกติ
- คง `script-src 'self'` และ `connect-src 'self'` ของหน้าแอป เพิ่ม `frame-src` เฉพาะ origin ของวิดเจ็ต วิดเจ็ตเป็น cross-origin iframe มี sandbox และใช้ referrer policy แบบ origin
- ธีมและรายการหุ้นเปลี่ยนแล้วสร้างวิดเจ็ตใหม่ ปุ่มอัปเดตเปิดการเชื่อมต่อใหม่ ผล API ที่กลับมาหลัง logout ถูกละทิ้งและ iframe ถูกลบออกจากหน้าทันที

## การตรวจ

Playwright ตรวจบัญชีที่ไม่มีคีย์ รายการว่าง/หลายหุ้น ticker แบบ BRK.B ธีมมืด/สว่างที่ 390/768/1440px การอัปเดต ลิงก์เมื่อวิดเจ็ตไม่โหลด ราคาจาก API ที่ยังมีบางส่วน และผลที่กลับมาหลัง logout การตรวจใน CI ใช้ข้อมูล fixture ที่ระบุชัดเจน การตรวจวิดเจ็ตจริงแยกต่างหากในเบราว์เซอร์ พบราคาของ NVDA และหุ้นทั้ง 36 บริษัทที่ catalog รองรับ โดยไม่ตั้งคีย์
