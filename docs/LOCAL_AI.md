# ใช้ AI ออนไลน์ฟรีหรือ AI ในเครื่อง

การตั้งค่า Gemini/Groq บน Render และการค้นหาข่าวที่เกี่ยวข้อง: อ่าน [คู่มือ AI ออนไลน์ฉบับปัจจุบัน](AI_ONLINE.md) ก่อน ส่วนด้านล่างอธิบาย Ollama และ Groq บนคอมส่วนตัว

ตัวเลือกสรุปหัวข้อข่าว:

- **GroqCloud Free Plan + `qwen/qwen3.8-27b`** — ออนไลน์ เร็ว ไม่ใช้พื้นที่ GPU ในเครื่อง แต่ต้องสมัคร API key และหัวข้อข่าวจะถูกส่งไป Groq
- **Ollama + `qwen3:8b`** — ฟรีในเครื่อง ไม่ต้องสมัคร API และข้อมูลไม่ออกจากเครื่อง

โหมด `auto` เลือก Gemini เมื่อมีคีย์ มิฉะนั้นใช้ Groq เมื่อมีคีย์ และอาจใช้ Ollama ที่ตั้งไว้เป็นตัวสำรอง เครื่อง local ที่ไม่มีคีย์ใช้ Ollama ได้ ส่วน Render ต้องตั้ง AI ออนไลน์ตาม [คู่มือปัจจุบัน](AI_ONLINE.md) การ fallback ต้องมีบริการปลายทางทำงานจริง

## ใช้ Groq ออนไลน์ฟรี

1. สมัครที่ [GroqCloud Console](https://console.groq.com/) แล้วสร้าง key ที่ [API Keys](https://console.groq.com/keys)
   หากเคยส่ง key ในแชตหรือเผยแพร่ที่อื่น ให้เพิกถอน key นั้นและสร้างใหม่ก่อน
2. เปิดไฟล์ `.env` ในโฟลเดอร์ `stocklens` แล้วเพิ่ม โดยไม่ส่ง key ในแชตหรือ GitHub:

   ```dotenv
   AI_ENABLED=true
   AI_PROVIDER=auto
   GROQ_API_KEY=ใส่_key_ของคุณ
   GROQ_MODEL=qwen/qwen3.8-27b
   ```

3. หยุดแล้วเปิด StockLens ใหม่ด้วย `npm.cmd start`
4. Login → **AI Insights** หากพร้อมจะเห็นป้าย “Groq ออนไลน์พร้อมใช้”

Free Plan มี rate limit และเปลี่ยนแปลงได้ ตรวจค่าปัจจุบันที่ [Groq Rate Limits](https://console.groq.com/docs/rate-limits) หากโควตาหมด แอปจะลอง Ollama ในเครื่องและติดป้ายว่าใช้ตัวสำรองอัตโนมัติ หากทั้งสองทางไม่พร้อม หน้า Insights จะแสดงหัวข้อพร้อมลิงก์ต้นทาง โดยระบุว่าไม่ใช่สรุป AI

เมื่อใช้ Groq แอปส่งข้อความข่าวหรือเนื้อหาบทความและคำถามที่เกี่ยวข้อง ตามโหมดที่เลือก ไม่ส่งชื่อ อีเมล รหัสผ่าน หรือ API key ไปกับ prompt ผลสรุปอาจถูก cache ในฐานข้อมูล

## ใช้ Ollama ในเครื่อง

Ollama ไม่ต้องสมัครบริการ AI และไม่มีค่า API ข้อความหัวข้อข่าวถูกส่งระหว่าง StockLens กับ `127.0.0.1` เท่านั้น โมเดลประมาณ 5.2 GB เหมาะกับเครื่องที่มี GPU RAM ประมาณ 8 GB แต่คำตอบแรกอาจใช้เวลาสักครู่

## ติดตั้งบน Windows

1. ดาวน์โหลด Ollama จาก [หน้า Download ทางการ](https://ollama.com/download/windows) แล้วติดตั้ง
2. เปิด PowerShell ใหม่ แล้วดาวน์โหลดโมเดลครั้งเดียว:

   ```powershell
   ollama pull qwen3:8b
   ```

3. ตรวจว่าโมเดลพร้อมด้วย `ollama list`
4. เปิด StockLens ใหม่ด้วย `npm.cmd start` จากนั้น Login → **AI Insights** → เลือกบริษัทที่มีข่าว → **สรุปหัวข้อข่าวด้วย AI**

หากต้องการบังคับใช้ Ollama แม้มี Groq key ให้ใส่ `AI_PROVIDER=ollama` หากต้องการปิด AI ใส่ `AI_ENABLED=false` แล้ว restart StockLens ห้ามเปลี่ยน `OLLAMA_URL` เป็นเครื่องภายนอก ระบบอนุญาตเฉพาะ localhost

## ถ้า AI ยังไม่พร้อม

- `ollama` ไม่พบ: ปิดแล้วเปิด PowerShell ใหม่ หรือเปิด Ollama จาก Start Menu
- ขึ้น “ยังไม่พบโมเดล”: รัน `ollama pull qwen3:8b` ให้เสร็จ และตรวจพื้นที่ว่างอย่างน้อย 6 GB
- ไม่มีหัวข้อข่าว: เปิดฟีดบริษัทหรือฟีดข่าวการเงินสำหรับหุ้นที่เลือกในหน้าแหล่งข้อมูล; ฟีดการเงินต้องมี Finnhub key
- ตอบช้า: คำตอบแรกต้องโหลดโมเดลเข้า GPU; ผลเดิมจะถูกเก็บใน SQLite และเปิดครั้งต่อไปเร็วขึ้น

## ขอบเขตความสามารถ

AI Insights รองรับสรุปและถามจาก **เนื้อหาบทความที่อ่านได้จริง** ของแหล่งที่อนุญาต ส่วนค้นข่าวย้อนหลังบางโหมดใช้หัวข้อและ metadata จึงต้องดูขอบเขตบนผลลัพธ์ อ่าน [ขอบเขตบทความ](ARTICLE_SUMMARIES.md) ส่วนแนวโน้มใช้กราฟ/สัญญาณ TradingView หรือผลทดสอบ Alpha Vantage ตามข้อมูลที่พร้อม แยกจากโมเดลสรุปข่าว อ่าน [ราคาและแนวโน้ม](PRICE_WIDGETS.md) และ [ข้อจำกัด](KNOWN_LIMITATIONS.md)

Custom GPT ที่สร้างใน ChatGPT ใช้ตรงกับ backend นี้ไม่ได้โดยไม่มี API และระบบยืนยันตัวตนแยก Groq และ Ollama จึงเป็นสองตัวเลือกฟรีที่แอปรองรับโดยตรง
