# AI ออนไลน์และข่าวฟรี

StockLens มีโหมดสรุปหัวข้อจาก RSS และโหมดอ่านเนื้อหาจากลิงก์บทความที่รองรับ พร้อมแหล่งอ้างอิงจริง ไม่เปิด Search Grounding ที่คิดค่าบริการ และไม่อ้างว่าโมเดลค้นเว็บเอง

หากไม่มีคีย์หรือบริการ AI ขัดข้อง ส่วน **ค้นหาข่าวที่เกี่ยวข้อง** ยังใช้ได้ จะแสดงหัวข้อ เวลา และลิงก์ต้นทางใน **แหล่งอ้างอิง** โดยไม่เรียกโมเดลหรือสร้างบทวิเคราะห์จำลอง หากไม่มีข่าวที่เปิดไว้ แอปจะแจ้งให้เลือกแหล่งข่าวก่อน

## ตั้งบน Render

เปิด service `stocklen` → **Environment** กรอกชื่อในช่อง KEY และค่าลงช่อง VALUE แล้วกด **Save and deploy** การ Save only ยังไม่เปลี่ยนค่าของ process ที่กำลังรัน ไม่ต้องนำคีย์มาใส่ในแชตหรือ Git

| KEY | VALUE |
| --- | --- |
| `AI_ENABLED` | `true` |
| `AI_PROVIDER` | `auto` |
| `GEMINI_API_KEY` หรือ `GROQ_API_KEY` | คีย์ของบัญชีเจ้าของจากผู้ให้บริการที่เลือก |
| `AI_DAILY_LIMIT` | `20` (จำนวนครั้งต่อวันต่อผู้ให้บริการออนไลน์ รวมทุกบัญชี) |

เลือกเพียงบริการเดียวก่อน ใช้บัญชี Free โดยไม่เปิด Billing หรือเพิ่มบัตร แอปไม่ได้เปิดแผนจ่ายเงินให้ แต่ไม่สามารถเปลี่ยนการตั้งค่า Billing ของบัญชีผู้ให้บริการแทนเจ้าของได้ โควตาจริงขึ้นกับบัญชีและอาจต่ำกว่าขีดจำกัดในแอป

- **Gemini:** สร้างที่ [Google AI Studio API keys](https://aistudio.google.com/api-keys) ค่าเริ่มต้น `GEMINI_MODEL=gemini-3.5-flash-lite` ซึ่งมี Free tier ตาม [ราคาทางการ](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite) ณ 13 พฤศจิกายน 2026 หากถูกส่งไปหน้า access troubleshooting ให้ตรวจข้อกำหนดอายุ การยืนยันบัญชี ภูมิภาค หรือสิทธิ์ Workspace ตาม [คู่มือ Google](https://aistudio.google.com/docs/troubleshoot-ai-studio) ไม่จำเป็นต้องเปิด Billing เพื่อแก้ปัญหานี้
- **Groq:** สร้างที่ [GroqCloud API Keys](https://console.groq.com/keys) ใช้ Free plan ค่าเริ่มต้น `GROQ_MODEL=qwen/qwen3.8-27b` ตรวจ [โมเดล](https://console.groq.com/docs/models), [โควตา](https://console.groq.com/docs/rate-limits) และ [Billing FAQs](https://console.groq.com/docs/billing-faqs) ของบัญชีตัวเอง

`auto` เลือก Gemini เมื่อมีคีย์ มิฉะนั้นใช้ Groq พร้อม Ollama สำรอง หากไม่มีคีย์บน Render จะรายงาน Gemini ว่ายังไม่ตั้งค่า และยังค้นหาข่าวที่เกี่ยวข้องได้ เครื่อง local ยังคงเลือก Ollama เมื่อไม่มีคีย์ หากต้องการบังคับผู้ให้บริการให้ตั้ง `AI_PROVIDER=gemini`, `groq` หรือ `ollama` ตามจริง อย่าบังคับ `ollama` บน Render ที่ไม่ได้ติดตั้งโมเดล

## ตรวจหลัง deploy

เข้า [StockLens](https://stocklen-znwy.onrender.com/) → AI Insights → เลือกบริษัทและบทความที่เปิดแหล่งข่าวไว้ แล้วกด **อ่านและสรุปเนื้อหา** เมื่อสำเร็จต้องมีชื่อผู้ให้บริการ ข้อความสรุปไทย เวลา และลิงก์ต้นทาง ลอง **ถาม AI เกี่ยวกับบทความนี้** เพื่อยืนยัน generation จริง การเห็นโมเดลใน status อย่างเดียวไม่ยืนยันว่ามีโควตาสรุป

หากโควตาหมด ให้ใช้ส่วน **ค้นหาข่าวที่เกี่ยวข้อง** ไม่มีการลองโมเดลเสียเงินหรือเปิดบริการค้นเว็บอื่นโดยอัตโนมัติ คำขอสร้างคำตอบออนไลน์มีขีดจำกัดที่เก็บในฐานข้อมูลข้ามการรีสตาร์ท ผลสรุปเดิมใช้ cache โดยไม่เรียกโมเดลซ้ำ

คำถามและข้อมูลข่าวถูกส่งให้ผู้ให้บริการที่เลือก ชื่อบัญชี อีเมล รหัสผ่าน และคีย์ไม่อยู่ใน prompt ผลสรุปอาจผิดและไม่ใช่คำแนะนำลงทุน ราคาหุ้น/กราฟย้อนหลังเป็นบริการแยก มีวิดเจ็ตฟรีและข้อมูล API ตาม [คู่มือราคา](PRICE_WIDGETS.md)

## ธีม

ปุ่มรูปดวงอาทิตย์/ดวงจันทร์ด้านบนสลับ **สว่าง ↔ มืด** ใช้ได้ทั้งก่อนและหลังเข้าสู่ระบบ จำค่าบนอุปกรณ์และซิงก์ระหว่างแท็บของเว็บเดียวกัน ไม่ต้องสร้างบัญชีเพื่อเลือกธีม

## สรุปเนื้อหาบทความ

ใน AI Insights เลือกบริษัท แล้วใช้ส่วน **สรุปเนื้อหาบทความ** เลือกข่าวและกด **อ่านและสรุปเนื้อหา** หรือกด **สรุปเนื้อหา** ใต้ข่าวในหน้าข่าว แอปจะดึงหน้าเว็บ แยกข้อความบทความ แล้วส่งให้ผู้ให้บริการ AI ที่เลือก รองรับบทความสาธารณะของ Apple, Microsoft, NVIDIA และ Netflix ที่อยู่ในรายการข่าวและเปิดแหล่งนั้นไว้

เมื่อดึงหรือแยกเนื้อหาไม่ได้ จะแจ้งข้อผิดพลาดและให้เปิดต้นฉบับ กรณีบทความยาวเกินขอบเขตข้อความจะแสดง **อ่านบางส่วน** ช่อง **ถาม AI เกี่ยวกับบทความนี้** ใช้เนื้อหาของบทความที่เลือกและถามได้ก่อนกดสรุป โหมดค้นข่าวย้อนหลังในหน้าค้นหาบริษัทยังใช้หัวข้อข่าว โหมดเนื้อหาเป็นการสรุปบทความที่เลือกทีละเรื่อง ไม่ใช่การค้นทุกเว็บ [รายละเอียดและการตรวจ](ARTICLE_SUMMARIES.md)
