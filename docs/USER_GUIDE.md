# คู่มือ StockLens 0.9.2 — ข่าวบริษัทสหรัฐฯ / PWA

[ติดตั้งทุกอุปกรณ์](INSTALLATION.md) · [เกี่ยวกับแอป](ABOUT.md) · [คู่มือทั้งหมด](README.md)

## 1. เปิดแอป

เปิด [StockLens ออนไลน์](https://stocklen-znwy.onrender.com/) แล้วสมัครบัญชีหรือเข้าสู่ระบบได้เลย หากติดตั้งไว้แล้วให้เปิดจากไอคอน StockLens บนเครื่อง ข่าว ราคา และ AI ต้องใช้อินเทอร์เน็ต โฮสต์ฟรีอาจใช้เวลาปลุกบริการเมื่อไม่ได้ใช้งาน

ต้องการติดตั้งบน Android, Windows, macOS, iPhone/iPad หรือ Linux ให้ดู [วิธีติดตั้ง](INSTALLATION.md) การใช้แอปออนไลน์ไม่ต้องติดตั้ง Node.js หรือเปิดเซิร์ฟเวอร์บนเครื่องตัวเอง ส่วนการรันซอร์สโค้ดดู [คู่มือนักพัฒนา](DEVELOPMENT.md)

## 2. สมัครสมาชิกและเก็บรหัสกู้คืน

1. กรอกชื่อ อีเมล รหัสผ่าน 10–128 ตัวอักษร และยืนยันรหัสผ่าน ใช้ตัวอักษรอังกฤษ A–Z, a–z ตัวเลข 0–9 และสัญลักษณ์มาตรฐาน หากพิมพ์หรือวางอักษรภาษาอื่น แอปจะปฏิเสธอักษรนั้นและเตือนสีแดงใต้ช่อง ให้กรอกใหม่ด้วยอักขระที่รองรับ
2. กดสร้างบัญชี หน้าถัดไปแสดง **รหัสกู้คืนครั้งเดียว** คัดลอกเก็บในตัวจัดการรหัสผ่านหรือที่ปลอดภัยก่อน Login
3. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่สมัคร เมื่อเปิดระบบรหัสอีเมลแล้ว แอปจะส่งรหัส 6 หลักให้กรอกในหน้าถัดไป รหัสหมดอายุใน 10 นาทีและใช้ได้ครั้งเดียว หากยังไม่ได้ตั้ง SMTP แอปจะเข้าสู่ระบบด้วยรหัสผ่านตามเดิม

ผู้ที่มีรหัสกู้คืนและอีเมลสามารถเปลี่ยนรหัสผ่านได้ อย่าแชร์รหัสนี้ หากรีเฟรชก่อนเก็บ ให้ Login แล้วไปการแจ้งเตือน → สร้างรหัสกู้คืนใหม่ โดยยืนยันรหัสผ่านปัจจุบัน รหัสเดิมจะถูกยกเลิกทันที บัญชีรุ่นเก่าต้องทำขั้นตอนนี้เพื่อเปิดใช้การกู้บัญชี

ลืมรหัสผ่าน: หน้า Login → ลืมรหัสผ่าน? ใช้รหัสกู้คืน → กรอกอีเมล รหัสกู้คืน และรหัสผ่านใหม่ → เก็บรหัสกู้คืนชุดใหม่ ระบบยกเลิกเซสชันทุกอุปกรณ์ หากไม่มีทั้งรหัสผ่านและรหัสกู้คืน จะยังไม่มีวิธีกู้ผ่านอีเมล

บัญชีที่เคยเปิด Authenticator จะยังใช้รหัสจากแอปนั้นในหน้าถัดไปจนกว่าจะปิดเองที่ **การแจ้งเตือน → บัญชีและความปลอดภัย** เมื่อปิดแล้วและระบบรหัสอีเมลพร้อม Login ครั้งถัดไปจะใช้รหัสอีเมล การใช้รหัสกู้คืนบัญชีเพื่อเปลี่ยนรหัสผ่านจะปิด Authenticator และออกจากระบบทุกอุปกรณ์ หากต้องการลบบัญชี ใช้ปุ่ม **ลบบัญชี** ในหน้าเดียวกัน กรอกอีเมล รหัสผ่าน และรหัส Authenticator ถ้าเปิดอยู่ ข้อมูลในฐานข้อมูลใช้งานจะถูกลบ แต่สำเนาสำรองเก่าต้องจัดการแยกต่างหาก

### รหัสอีเมลหลังกรอกรหัสผ่าน

ระบบนี้ต้องมีบัญชีส่ง SMTP ก่อนจึงจะใช้งานจริงได้ หากใช้ Gmail ส่วนตัว ให้เปิดการยืนยันสองขั้นตอนของ Google แล้วสร้าง [App Password](https://support.google.com/mail/answer/185833) บนบัญชีผู้ส่ง ใส่ค่าเหล่านี้ใน `.env` บนเครื่องเซิร์ฟเวอร์เท่านั้น:

```dotenv
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=อีเมลผู้ส่งจริง
SMTP_PASS=App Password ของบัญชีผู้ส่ง
SMTP_FROM=อีเมลผู้ส่งจริง
EMAIL_LOGIN_OTP_ENABLED=false
```

รีสตาร์ทแอปแล้วลองส่งลิงก์ยืนยันจากหน้า **การแจ้งเตือน → บัญชีและความปลอดภัย** ไปยังอีเมลจริงที่รับได้ก่อน เมื่ออีเมลส่งและรับสำเร็จ ค่อยเปลี่ยน `EMAIL_LOGIN_OTP_ENABLED=true` แล้วรีสตาร์ทอีกครั้ง บัญชีที่ไม่มีอีเมลรับได้ เช่นบัญชีทดสอบ `@stocklens.example` จะรับรหัสไม่ได้หลังเปิดตัวเลือกนี้ ต้องสมัครหรือใช้บัญชีที่ผูกอีเมลจริง เก็บ App Password ใน `.env` เท่านั้นและอย่าส่งในแชตหรือ Git หากไม่มีอีเมลเข้าลองดู Junk/Spam และรออย่างน้อย 1 นาทีก่อนขอใหม่

## 3. เลือกบริษัทที่อยากติดตาม

ไปที่ **สิ่งที่ติดตาม** หรือ **ค้นหาบริษัท** แล้วกดติดตาม รองรับ AAPL, MSFT, NVDA, AMZN, GOOGL, META, TSLA, BRK.B, JPM, V, WMT และ KO การติดตามหมายถึงต้องการเห็นข่าวและราคาประกอบ ไม่ได้หมายความว่าคุณถือหุ้น

หากอัปเกรดจากรุ่นที่เคยเก็บพอร์ต ระบบจะย้ายเฉพาะ ticker สหรัฐฯ ที่รองรับมาเป็นรายการติดตาม แล้วลบจำนวนหุ้นและต้นทุนออกจาก state โดยอัตโนมัติ

### ราคาของบริษัทที่ติดตาม

หน้า **ภาพรวม** และ **ติดตาม** แสดงตารางราคาจาก TradingView ได้โดยไม่ต้องสมัครคีย์ราคา ตารางมีข้อมูลล่าช้าตามตลาดและเปลี่ยนตามรายการที่คุณติดตาม กด **อัปเดตราคา** เพื่อเปิดตารางใหม่ ใช้ได้ทั้งธีมมืดและสว่าง เวลา **เปิดตาราง** เป็นเวลาที่เปิดวิดเจ็ต หากตารางไม่แสดง มีลิงก์หุ้นแต่ละบริษัทให้เปิดบน TradingView ได้

หากตั้ง Finnhub key ไว้ แอปยังแสดงราคา API พร้อมเวลาราคาและสถานะข้อมูลเก่า เมื่อราคา API ไม่มีเลยจะใช้ตารางฟรีแทน หากบางรายการขาดหายสามารถกด **เปิดตารางราคาฟรีจาก TradingView** ได้ ตารางภายนอกโหลดตรงจากผู้ให้บริการ ไม่มีการนำข้อมูลราคาจากวิดเจ็ตไปคำนวณ AI หรือผลตอบแทนพอร์ต ดู [รายละเอียดและขอบเขต](PRICE_WIDGETS.md)

### เปรียบเทียบราคาย้อนหลัง

กด **เปรียบเทียบย้อนหลัง** ใต้ตารางราคา เลือกบริษัทที่ติดตาม แล้วเลือก **เมื่อวาน / 1 สัปดาห์ / 1 เดือน / 3 เดือน / 6 เดือน / 1 ปี** กราฟแสดงราคา ส่วนต่าง USD และเปอร์เซ็นต์ตามช่วงที่เลือก แตะหรือชี้เส้นเพื่อดูราคาและวันที่ของจุดนั้นได้

กราฟย้อนหลังใช้ TradingView ฟรีพร้อมข้อมูลในตัว ไม่ต้องเพิ่มคีย์หรือแพ็กเกจย้อนหลังของ Finnhub ข้อมูลมีความล่าช้าตามตลาด เวลาและจุดราคาเป็นไปตามผู้ให้บริการ “เมื่อวาน” หมายถึงราคาปิดวันซื้อขายก่อนหน้า ไม่ใช่วันหยุดตามปฏิทิน กราฟเริ่มโหลดเมื่อกดเปิดการเปรียบเทียบเท่านั้น

ตารางราคาจาก Finnhub แสดงส่วนต่างเทียบราคาปิดก่อนหน้าใต้ราคาปัจจุบันด้วย ถ้า Finnhub ไม่ส่งราคาปิดก่อนหน้าที่ตรวจสอบได้ แอปจะไม่สร้างตัวเลขส่วนต่างขึ้นเอง

## 4. ค้นหาบริษัท

ใช้เมนูค้นหาบริษัท ค้นชื่ออังกฤษ ชื่อไทย หรือ ticker เช่น `แอปเปิล`, `MSFT`, `NVIDIA` เปิดข้อมูลบริษัทเพื่อไปเว็บไซต์นักลงทุนสัมพันธ์หรือค้นเอกสาร SEC EDGAR แล้วเลือกติดตามข่าว

รายชื่อเป็น directory 36 บริษัทที่จดทะเบียนในสหรัฐฯ ไม่ใช่ระบบค้นหาทุกหลักทรัพย์ หุ้นใหม่ที่เพิ่ม ได้แก่ AVGO, ADBE, CSCO, IBM, UBER, ABNB, PYPL, PLTR, SBUX, NKE, HD และ CAT ไอคอนในหน้าค้นหา/ข่าว/รายการติดตามมาจากเว็บไซต์บริษัท 33 แห่ง; GOOGL, BRK.B และ PEP แสดงตัวย่อแทน

ช่องค้นหาช่องเดียวกันรับคำอิสระ เช่น `PTT`, `หุ้นญี่ปุ่น` หรือชื่อบริษัทที่ยังไม่อยู่ในแอป จากนั้นกด **ค้นใน Google News** หรือ **ค้นใน Bing News** เพื่อเปิดผลบนเว็บของผู้ให้บริการในแท็บใหม่ เมื่อกด คำค้นจะถูกส่งไปยังเว็บนั้น ผลค้นไม่ได้หมายถึงทุกข่าวบนอินเทอร์เน็ต และผลค้นภายนอกไม่ถูกส่งเข้า AI/แจ้งเตือนของ StockLens

ถ้าต้องการให้ AI สรุปข่าวย้อนหลัง ให้เปิดหน้า **ค้นหาบริษัท** แล้วทำตามขั้นตอนนี้:

สำหรับบริษัทในรายการ 36 ตัว กด **ดูข้อมูลบริษัท** แล้วกด **ดูข่าวย้อนหลังและให้ AI สรุป** เพื่อไปยังขั้นตอนเลือกจำนวนเดือนทันที

1. พิมพ์ชื่อบริษัทหรือตัวย่อ เช่น `NVIDIA` แล้วกด **ค้นหาบริษัท** แอปจะส่งคำค้นไป Finnhub ต้องตั้ง `FINNHUB_API_KEY` ใน `.env` ก่อน
2. เลือกบริษัทจากผลค้นที่มีชื่อและ ticker ตรงกัน ระบบนี้ค้นบริษัทนอก 36 ตัวที่ติดตามในแอปได้ แต่ยังเพิ่มเข้ารายการติดตามไม่ได้
3. เลือกข่าวย้อนหลัง **1, 3 หรือ 6 เดือน** แล้วกด **ค้นข่าวและสรุปด้วย AI** แอปดึงข่าวทีละเดือน คัดหัวข้อที่เกี่ยวข้อง และส่งหัวข้อสูงสุด 10 รายการให้ Groq หรือ Ollama ที่ตั้งค่าไว้
4. อ่านสรุปและเปิดลิงก์ข่าวด้านล่างเพื่อตรวจต้นทาง ถ้า AI ไม่พร้อม แอปยังแสดงข่าวที่ดึงได้ หากไม่มีข่าวที่เกี่ยวข้องจะไม่สร้างสรุปจำลอง

ผลนี้ไม่ใช่ข่าวทั้งหมด: Finnhub อาจจำกัดผลต่อเดือนและโควตา คำค้นบางบริษัทอาจมีข่าวไม่ครบหรือชื่อคล้ายกัน การคัดเลือกใช้ชื่อบริษัทในหัวข้อ/คำอธิบาย ไม่ได้อ่านข้อความเต็มของบทความ ข้อความจาก AI อาจผิดและไม่ใช่คำแนะนำลงทุน คำค้นบริษัทส่งไป Finnhub; หากใช้ Groq ออนไลน์ หัวข้อข่าว แหล่งข่าว วันที่ และ ticker จะถูกส่งไป Groq ด้วย

## 5. ข่าวและเว็บไซต์ต้นทาง

แอปดึงหัวข้อ RSS จริงจาก:

- [Apple Newsroom](https://www.apple.com/newsroom/) — AAPL
- [Microsoft News](https://news.microsoft.com/) — MSFT
- [NVIDIA Newsroom](https://nvidianews.nvidia.com/) — NVDA
- [Netflix Investor News](https://ir.netflix.net/) — NFLX

หากตั้ง Finnhub key แอปดึงข่าวการเงินสำหรับทั้ง 36 บริษัทจาก Finnhub อีกชุดหนึ่ง ข่าวติดชื่อสำนักจริง เช่น Yahoo, Seeking Alpha, Benzinga หรือ CNBC และมีลิงก์ต้นฉบับ ฟีดนี้ตรวจไม่เกินทุก 4 ชั่วโมง โดยไม่รับประกันว่าทุกบริษัทจะมีข่าวใหม่ในทุกวัน และอาจเจอโควตาผู้ให้บริการ เมื่อติดตามหุ้นตัวใหม่ แอปจะเพิ่มฟีด Finnhub ของหุ้นนั้นให้อัตโนมัติถ้ายังไม่มี

ตรวจฟีดเมื่อเริ่มเซิร์ฟเวอร์และทุก 15 นาที หากเปิดหน้าแอปค้างไว้จะโหลดรายการจากเซิร์ฟเวอร์ทุก 5 นาที กดรีเฟรชเพื่ออ่านรายการที่เซิร์ฟเวอร์มีล่าสุด ไม่ได้บังคับเว็บไซต์ต้นทางให้ออกข่าวใหม่

เลือก **สิ่งที่ติดตาม** เพื่อกรองข่าว กดหัวข้อเพื่ออ่านต้นฉบับ มีเวลาเผยแพร่และสถานะของแต่ละแหล่งข่าว หากดึงใหม่ล้มเหลวจะยังอ่านข้อมูลเก่าพร้อมป้ายเตือนได้ เวลาเผยแพร่อาจเก่ากว่าเวลาดึงข้อมูล และไม่มีข่าวใหม่ในบางวัน

หน้าแหล่งข้อมูล: เปิด/ปิดฟีดเพื่อเปลี่ยนรายการข่าวของบัญชี บัญชีเดิมเพิ่มฟีดเริ่มต้นได้จากปุ่มเพิ่มฟีด เพิ่มฟีด [Federal Reserve ข่าวประชาสัมพันธ์](https://www.federalreserve.gov/feeds/press_all.xml) หรือ [นโยบายการเงิน](https://www.federalreserve.gov/feeds/press_monetary.xml) ด้วยปุ่มหรือ URL ตรงตามนี้แล้วแอปจะดึงหัวข้อ RSS จริง ฟีดเหล่านี้เป็นข่าวภาพรวม ไม่ผูกกับหุ้นตัวใดและไม่เข้าโหมด AI สรุปหุ้นรายบริษัท URL อื่นที่ยังไม่ตรวจสอบเป็นบุ๊กมาร์ก ไม่ถูกเซิร์ฟเวอร์ดึงข้อมูล รายการรวมเพิ่มได้สูงสุด 100 เว็บไซต์

ข่าวจาก RSS บริษัทเป็นประกาศบริษัท ฟีด Federal Reserve เป็นข่าวหน่วยงานทางการ ส่วนข่าวผ่าน Finnhub เป็นสื่อการเงินที่แสดงชื่อผู้เผยแพร่ ยังไม่ได้ตรวจข้อเท็จจริงข้ามสำนักหรือยืนยันข่าวคู่ค้า และไม่คัดลอกบทความเต็ม หน้า AI Insights อ่านเนื้อหาจากบทความที่รองรับ ส่วนการค้นข่าวย้อนหลังในหน้าค้นหาบริษัทยังสรุปจากหัวข้อข่าว

## 6. AI และการแจ้งเตือน

เปิดหน้า **AI Insights** แล้วเลือกบริษัทในส่วน **สรุปเนื้อหาบทความ** เลือกข่าวและกด **อ่านและสรุปเนื้อหา** เมื่อ AI พร้อม แอปจะอ่านเนื้อหาจริงก่อนสรุป พร้อมลิงก์ต้นทาง เวลาอ่าน และสถานะอ่านครบขอบเขต/อ่านบางส่วน

ในส่วนเดียวกัน กรอกคำถามใน **ถาม AI เกี่ยวกับบทความนี้** แล้วกด **ถาม AI** ระบบจะอ่านเนื้อหาของบทความที่เลือกเพื่อตอบ แม้ยังไม่ได้กดสรุป คำตอบมีแหล่งอ้างอิงและเวลา หากเนื้อหาไม่พอจะบอกว่าข้อมูลไม่พอ คำถามยาว 5–300 ตัวอักษร ใช้โควตา AI ร่วมกับการสรุป คำถามและคำตอบแยกตามบทความ เก็บเฉพาะในหน้าเว็บและล้างเมื่อออกจากระบบหรือรีเฟรช เนื้อหาและคำถามส่งไปผู้ให้บริการ AI ที่ตั้งไว้

ด้านล่าง กด **ค้นหาข่าวที่เกี่ยวข้อง** เพื่อรวบรวมข่าวของบริษัทที่เลือกจากแหล่งที่เปิดไว้ ใช้ได้แม้ AI ไม่พร้อมและไม่เรียกโมเดล รายการข่าวพร้อมชื่อผู้เผยแพร่ เวลา และลิงก์ต้นทางจะแสดงทันทีหลังค้นหา และเลื่อนไปยังผลลัพธ์ให้อัตโนมัติ กด **แหล่งอ้างอิง** เพื่อพับหรือเปิดรายการได้

ส่วน **แนวโน้มจากราคาย้อนหลัง** ใช้กราฟราคา 1 ปีและสรุปสัญญาณ TradingView ได้ฟรีโดยไม่ต้องเพิ่มคีย์ เลือกตัวชี้วัด **รายวัน / รายสัปดาห์ / รายเดือน** แล้วกด **อัปเดตแนวโน้ม** เพื่อตรวจใหม่ ข้อมูลอาจล่าช้าตามตลาดและสัญญาณไม่ใช่ผลทดสอบย้อนหลังของแอป [รายละเอียดแหล่งข้อมูล](PRICE_WIDGETS.md)

หากเพิ่ม Alpha Vantage key ฟรีใน `.env` หน้าเดียวกันจะแสดงกราฟราคาปิดรายสัปดาห์ที่จบแล้วสูงสุด 104 สัปดาห์ และทดสอบกฎแนวโน้ม 4 สัปดาห์เพื่อดูผลสัปดาห์ถัดไป โดยใช้ราคาปิดแบบปรับ split/ปันผลและทดสอบย้อนหลัง 5 ปี ถ้า backtest ไม่ผ่านจะแสดงเหตุผลและไม่ให้สัญญาณ แต่ยังแสดงแนวโน้ม 4 สัปดาห์ที่เกิดขึ้นแล้วโดยระบุว่าไม่ใช่คำทำนาย ไม่มีเปอร์เซ็นต์ความน่าจะเป็นหรือผลทำนายจาก Groq Custom GPT เดิมไม่ได้เชื่อมตรงกับแอป

หน้าแจ้งเตือนมีรายการข่าวตามบริษัทที่ติดตามหรือทุกฟีดที่เปิดไว้ ปิด “แสดงและแจ้ง Push ข่าวบริษัทที่เลือก” เพื่อปิดทั้งรายการและการส่ง Push กด **เปิด Push บนอุปกรณ์นี้** แล้วอนุญาตเบราว์เซอร์ กด **ส่งทดสอบ** เพื่อตรวจการรับจริง Web Push อาจแจ้งข่าวใหม่เมื่อปิดหน้าแอปแต่เซิร์ฟเวอร์ยังทำงานและอุปกรณ์ออนไลน์ การตั้งเวลารายวันและแนวโน้ม AI เก็บเป็นความต้องการเท่านั้น ยังไม่มีอีเมลแจ้งข่าวหรือสรุปรายวัน

## 7. ติดตั้งเป็นแอป

ดู [วิธีติดตั้งตามอุปกรณ์](INSTALLATION.md) สำหรับ Android APK/PWA, Windows, macOS, iPhone/iPad, Linux และ Chromebook ใช้ URL ออนไลน์เดียวกันได้ทุกเครื่อง และเปิดจากไอคอน StockLens หลังติดตั้ง

การติดตั้งไม่ได้ทำให้ข่าว ราคา หรือ AI ใช้งานแบบออฟไลน์ หากเครือข่ายขาดจะแสดงหน้าออฟไลน์และลองใหม่เมื่อเชื่อมต่อ ส่วนการรันเซิร์ฟเวอร์เองดู [คู่มือนักพัฒนา](DEVELOPMENT.md)

## 8. ออกจากระบบและดาวน์โหลดข้อมูล

กดปุ่มอักษรย่อบัญชีมุมขวาบนเพื่อเปิด **บัญชีของฉัน** แล้วกดปุ่มสีแดง **ออกจากระบบ** ที่ท้ายหน้า เซสชันอุปกรณ์นี้จะถูกยกเลิก หน้า **สิ่งที่ติดตาม** และเมนูเพิ่มเติมมีลิงก์ดาวน์โหลดข้อมูลบัญชี JSON ใช้ตรวจข้อมูลได้ แต่ยังนำกลับเข้าอัตโนมัติไม่ได้

## 9. เริ่มใช้งานครั้งแรก

หลังเข้าสู่ระบบครั้งแรกจะเข้าหน้าภาพรวมของแอปทันที เลือกบริษัทและแหล่งข่าวเพิ่มเติมภายหลังได้ หากต้องการตั้งค่ารวมในหน้าเดียว เปิด **เพิ่มเติม → เริ่มใช้งาน** ค้นด้วยชื่อไทย อังกฤษ หรือ ticker เลือกได้หลายบริษัท แล้วกด **บันทึกและเปิดข่าวของฉัน** รายการกับสถานะการตั้งค่าจะบันทึกพร้อมกัน หรือกด **ข้ามไปก่อน** เพื่อกลับไปอ่านข่าวโดยไม่เปลี่ยนรายการ

หากบันทึกไม่สำเร็จ ช่องที่เลือกจะยังอยู่ หากอีกแท็บหรือหน้าอื่นแก้รายการไปแล้ว แอปจะไม่เขียนทับ ให้กด **โหลดรายการล่าสุด** แล้วตรวจตัวเลือกใหม่ก่อนบันทึก

## 10. จัดการอุปกรณ์ที่เข้าสู่ระบบ

เข้า **เพิ่มเติม → อุปกรณ์ที่เข้าสู่ระบบ** ดูเบราว์เซอร์/ระบบโดยประมาณ เวลาเข้าใช้งานล่าสุดและเวลาหมดอายุ อุปกรณ์นี้มีป้ายกำกับ เลือกออกจากระบบทีละอุปกรณ์หรืออุปกรณ์อื่นทั้งหมด โดยแอปจะขอยืนยันก่อน หากเลือกอุปกรณ์นี้จะกลับหน้าล็อกอิน

แสดงเฉพาะเซสชันของบัญชีคุณ ไม่แสดง token หรือ IP ชื่อเบราว์เซอร์เป็นข้อมูลโดยประมาณ หลายเบราว์เซอร์บนเครื่องเดียวอาจเป็นคนละรายการ การเพิกถอนลบ Push ที่ผูกกับเซสชันนั้นด้วย; Push ของเวอร์ชันเก่าที่ไม่ได้ผูกเซสชันยังคงอยู่จนกว่าจะปิดบนอุปกรณ์เดิม

## ปัญหาที่พบบ่อย

- เปิดไม่ได้: ตรวจอินเทอร์เน็ต ลองเปิดเว็บโดยตรง และรอให้โฮสต์ฟรีตื่นจากการพัก หากติดตั้งไม่สำเร็จดู [วิธีแก้ปัญหาการติดตั้ง](INSTALLATION.md#อัปเดต-ถอนการติดตั้ง-และแก้ปัญหา) ส่วนเซิร์ฟเวอร์ที่รันเองให้ตรวจ Terminal และพอร์ตตาม [คู่มือนักพัฒนา](DEVELOPMENT.md)
- ไม่มีข่าว: ดูสถานะแหล่งข่าว เปิดฟีดที่ต้องการ ตรวจอินเทอร์เน็ตของเซิร์ฟเวอร์ และตรวจว่ามี Finnhub key สำหรับข่าวสื่อการเงิน
- บันทึกชนกับอีกแท็บ: ระบบโหลดข้อมูลล่าสุดให้ ตรวจค่าก่อนแก้ใหม่
- ลอง Login หลายครั้งแล้วถูกจำกัด: รอ 15 นาที ห้ามกดซ้ำรัว ๆ
- โฮสต์ถูกลบ/ดิสก์หาย: ต้องกู้จาก backup ฐานข้อมูล ไม่สามารถกู้ด้วยรหัสกู้บัญชีได้

## ธีมและ AI ออนไลน์

ปุ่มธีมด้านบนสลับสว่างและมืด พร้อมจำค่าบนอุปกรณ์ หน้า AI Insights สรุปและถาม AI จากบทความที่รองรับได้เมื่อบริการพร้อม ส่วน **ค้นหาข่าวที่เกี่ยวข้อง** ใช้ได้แม้โควตา AI หมด ผู้ดูแลตั้งค่า Gemini/Groq ตาม [คู่มือ AI ออนไลน์](AI_ONLINE.md)

## บัญชีของฉัน

กดตัวอักษรบัญชีที่มุมขวาบนเพื่อดูชื่อ อีเมล จำนวนบริษัทที่ติดตาม และจำนวนแหล่งข้อมูลที่เปิดไว้ พร้อมรายการบริษัทและทางไปจัดการอุปกรณ์ การแจ้งเตือน/ความปลอดภัย แหล่งข้อมูล และดาวน์โหลดข้อมูล การกดตัวอักษรจะไม่ออกจากระบบ ปุ่ม **ออกจากระบบ** สีแดงอยู่ล่างสุดของหน้านี้ ใช้เพื่อออกเฉพาะอุปกรณ์ปัจจุบัน รายการติดตามยังอยู่ในบัญชี

## สรุปจากเนื้อหาเว็บ

กด **สรุปเนื้อหา** ใต้ข่าว หรือไป AI Insights → **สรุปเนื้อหาบทความ** → เลือกข่าว → **อ่านและสรุปเนื้อหา** ผลมีประเด็นจากเนื้อหา เวลาอ่าน และลิงก์ต้นฉบับ รองรับบทความสาธารณะจากบริษัทที่แอปรองรับ หากอ่านได้บางส่วนจะแจ้งไว้ หากเว็บปิดการอ่านอัตโนมัติจะไม่สร้างสรุปแทนจากหัวข้ออย่างเงียบ ๆ [ขอบเขตที่รองรับ](ARTICLE_SUMMARIES.md)
