# เกี่ยวกับ StockLens

[เปิดแอป](https://stocklen-znwy.onrender.com/) · [ติดตั้ง](INSTALLATION.md) · [คู่มือใช้งาน](USER_GUIDE.md) · [คู่มือทั้งหมด](README.md)

StockLens เป็นแอปภาษาไทยสำหรับรวมข่าวบริษัทสหรัฐฯ ที่คุณสนใจ อ่านเนื้อหาที่รองรับผ่านสรุป AI และเปิดต้นทางเพื่อตรวจข้อมูล พร้อมดูราคาและกราฟประกอบ ใช้ได้ผ่านเว็บ ติดตั้งเป็นเว็บแอปบนคอมพิวเตอร์และมือถือ หรือใช้ APK บน Android

## ทำอะไรได้บ้าง

| ส่วนของแอป | สิ่งที่ทำได้ |
| --- | --- |
| บริษัทและรายการติดตาม | ค้นชื่อหรือตัวย่อ เลือกติดตามจากรายชื่อบริษัทสหรัฐฯ ที่แอปรองรับ และจัดการรายการแยกตามบัญชี |
| ข่าวและแหล่งข้อมูล | เปิด/ปิดแหล่งข่าว อ่านหัวข้อพร้อมผู้เผยแพร่และเวลา เปิดบทความต้นทาง และค้นหาข่าวที่เกี่ยวข้อง |
| สรุปเนื้อหาบทความ | เลือกบทความสาธารณะจากแหล่งที่รองรับ อ่านสรุปภาษาไทยและสถานะอ่านครบหรือบางส่วน พร้อมแหล่งอ้างอิง |
| ถาม AI | ถามเกี่ยวกับบทความที่เลือกได้โดยไม่ต้องกดสรุปก่อน คำตอบอ้างอิงบทความนั้นและอาจตอบว่าข้อมูลไม่พอ |
| ราคาและกราฟ | ดูราคาพร้อมสถานะเวลา เปรียบเทียบวันซื้อขายก่อนหน้า, 1 สัปดาห์, 1/3/6 เดือน และ 1 ปี |
| แนวโน้ม | ดูกราฟและสัญญาณเทคนิครายวัน/สัปดาห์/เดือน ผลทดสอบจาก API ราคาย้อนหลังแสดงเฉพาะเมื่อมีข้อมูลที่ผ่านเงื่อนไข |
| บัญชีและอุปกรณ์ | ดูจำนวนบริษัท/แหล่งข่าวที่ติดตาม จัดการเซสชันของอุปกรณ์ ออกจากระบบ ส่งออกข้อมูล และลบบัญชี |
| การแสดงผล | ธีมสว่าง/มืด รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ |

## แหล่งข้อมูลและการใช้ AI

ข่าวบริษัทโดยตรงมาจาก Apple, Microsoft, NVIDIA และ Netflix มีข่าวการเงินและราคาจาก Finnhub เมื่อบริการถูกตั้งค่าไว้ และใช้วิดเจ็ต TradingView สำหรับราคา/กราฟบางส่วน รายชื่อบริษัทในแอปเป็นชุดที่คัดไว้ ไม่ใช่ทุกหลักทรัพย์ในโลก [รายละเอียดราคาและวิดเจ็ต](PRICE_WIDGETS.md)

การสรุปและถามบทความใช้ข้อความที่เซิร์ฟเวอร์ดึงและอ่านได้จากแหล่งที่อนุญาต โมเดลไม่ได้ค้นทุกเว็บไซต์ด้วยตัวเอง หากเว็บปิดกั้น อ่านไม่ได้ หรืออ่านได้บางส่วน แอปจะแสดงสถานะนั้น โหมดค้นข่าวย้อนหลังบางส่วนยังใช้เฉพาะหัวข้อและคำอธิบาย ให้ดูขอบเขตของผลลัพธ์แต่ละส่วน [ขอบเขตการอ่านบทความและการถาม AI](ARTICLE_SUMMARIES.md)

AI ออนไลน์ใช้ผู้ให้บริการที่ผู้ดูแลตั้งไว้ เช่น Groq หรือ Gemini ข้อความข่าว/บทความและคำถามที่เกี่ยวข้องจะถูกส่งให้บริการนั้นเพื่อสร้างคำตอบ ผู้ใช้แอปออนไลน์ไม่ต้องใส่ API key ของตัวเอง

## บัญชีและความเป็นส่วนตัว

- บัญชีและรายการติดตามเก็บฝั่งเซิร์ฟเวอร์ ใช้บัญชีเดิมกับเว็บและ APK ได้ แต่อาจต้องเข้าสู่ระบบแยกในแต่ละอุปกรณ์
- แอปเก็บข้อมูลบัญชี บริษัทและแหล่งข่าวที่เลือก รวมถึงข้อมูลที่จำเป็นต่อเซสชันและการตั้งค่า ไม่ขอจำนวนหุ้น ต้นทุน หรือมูลค่าพอร์ต
- ชื่อบัญชี อีเมล รหัสผ่าน และคีย์บริการไม่ได้รวมใน prompt ข่าวของ AI รหัสผ่านเก็บเป็น hash ส่วนคีย์บริการอยู่ฝั่งเซิร์ฟเวอร์
- ไปที่หน้าบัญชีเพื่อดูข้อมูลการติดตามและจัดการอุปกรณ์ ตัวเลือกส่งออก/ลบบัญชีและรหัสกู้คืนอยู่ในส่วนบัญชีและความปลอดภัยตาม [คู่มือ](USER_GUIDE.md)
- กราฟและลิงก์ข่าวภายนอกติดต่อผู้ให้บริการของตัวเอง การถอนแอปไม่ใช่การลบบัญชีบนเซิร์ฟเวอร์

## สถานะและข้อจำกัดสำคัญ

เว็บใช้งานผ่าน HTTPS แล้ว และมี **Android 0.9.2 Beta** ให้ดาวน์โหลดจาก [GitHub Releases](https://github.com/lew280352-sudo/StockLens/releases/tag/android-v0.9.2-beta.1) ส่วน APK เป็นตัวเปิดบริการเว็บออนไลน์ จึงต้องใช้อินเทอร์เน็ตและเบราว์เซอร์ที่รองรับ

โฮสต์ฟรีอาจพักเมื่อไม่ได้ใช้งาน ทำให้เปิดครั้งแรกช้าหรือหยุดรอบตรวจข่าวระหว่างพัก บริการข่าว/AI มีโควตาและอาจไม่พร้อมชั่วคราว ราคาอาจล่าช้าตามผู้ให้บริการ AI อาจผิดหรือขาดบริบท ควรตรวจต้นฉบับและไม่ใช้เป็นคำแนะนำลงทุน

การส่งอีเมลและ Push ถึงอุปกรณ์จริงยังไม่ได้ยืนยันครบ อย่าใช้เป็นช่องทางแจ้งเตือนที่ต้องได้รับแน่นอน [ดูสถานะและข้อจำกัดทั้งหมด](KNOWN_LIMITATIONS.md)
