# สรุปเนื้อหาจากบทความ

หน้า AI Insights เริ่มด้วย **สรุปเนื้อหาบทความ** พร้อม **ถาม AI เกี่ยวกับบทความนี้** ด้านล่างเป็น **ค้นหาข่าวที่เกี่ยวข้อง** ซึ่งรวบรวมหัวข้อและลิงก์ต้นทางโดยไม่เรียกโมเดล กด **สรุปเนื้อหา** ใต้ข่าวเพื่อไปส่วนบทความได้โดยตรง ใช้คีย์ Gemini/Groq เดิม ไม่มีบริการค้นเว็บที่คิดค่าใช้จ่ายเพิ่ม

รองรับ URL บทความสาธารณะในรายการข่าวจาก Apple Newsroom, Microsoft News/Blog, NVIDIA Newsroom และ Netflix Investor News ต้องเปิดแหล่งนั้นในบัญชีไว้ เว็บอื่นยังเปิดอ่านเป็นลิงก์ได้ แต่ยังไม่ถูกดึงเนื้อหามาสรุป ไม่ปลดหน้าเข้าสู่ระบบหรือ paywall

ผลระบุ **อ่านเนื้อหาแล้ว** เมื่อข้อความที่แยกได้อยู่ในขอบเขต หรือ **อ่านบางส่วน** เมื่อยาวเกินขอบเขต พร้อมเวลาอ่านและลิงก์ต้นทาง หากแยกข้อความไม่ได้หรือเว็บปิดการอ่านอัตโนมัติ จะแสดงข้อผิดพลาด คำถามใช้เนื้อหาบทความที่เลือกจริง รวมสถานะ complete/partial หากข้อมูลไม่พอตอบจะแจ้งตรง ๆ คำตอบอ้างอิงได้เฉพาะรหัสบทความนั้น คำถามและคำตอบเก็บในหน่วยความจำหน้าเว็บและล้างเมื่อออกจากระบบหรือรีเฟรช

## ขอบเขตการอ่าน

- POST `/api/ai/article` และ `/api/ai/article/ask` รับเฉพาะรหัสข่าวที่อยู่ในแหล่งที่เปิดไว้ ไม่รับ URL อิสระ ตรวจ session/แหล่งข่าวซ้ำหลังดึงเนื้อหาและหลัง generation
- HTTPS และ host/path ที่กำหนดไว้เท่านั้น ไม่ส่ง cookie หรือข้อมูลบัญชีไปเว็บข่าว ตรวจทุก redirect สูงสุดสามครั้ง ไม่ส่งต่อไป host ภายนอกรายการ
- HTML ไม่เกิน 1 MiB และเวลาเครือข่าย 12 วินาที ใช้ [Mozilla Readability](https://github.com/mozilla/readability) กับ [jsdom](https://github.com/jsdom/jsdom) ซึ่งไม่เปิด script execution หรือ resource loading ถอดเฉพาะข้อความ ไม่ส่ง HTML ไปแสดงในแอป
- ข้อความเข้าโมเดลไม่เกิน 12,000 UTF-8 bytes ต่อบทความ หากตัดจะระบุ partial ทั้งใน prompt และผล ตัวอ่านทำงานพร้อมกันไม่เกินสองหน้าและจำกัดงานค้าง
- Cache ข้อความที่ดึงได้ในฐานข้อมูลหกชั่วโมง หากแคชอ่านหรือเขียนไม่สำเร็จยังสรุปจากเนื้อหาที่ดึงสดได้ Cache ผล AI แยกจากโหมดหัวข้อโดยใช้ hash ของข้อความและรุ่นโมเดล ไม่เก็บบทความเต็มเป็นส่วนหนึ่งของผลตอบกลับ API
- คำถามยาว 5–300 ตัวอักษร ไม่รับ URL อิสระหรือเนื้อหาที่เบราว์เซอร์อ้างว่าอ่านมาเอง ตอบจากข้อความที่เซิร์ฟเวอร์อ่านจากแหล่งที่เปิดไว้เท่านั้น
- ใช้โควตา generation และการจำกัดคำขอร่วมกับ AI เดิม เว็บไซต์อาจปิดการเข้าถึงหรือเปลี่ยนโครงสร้างได้ จึงไม่รับประกันว่าอ่านได้ทุกบทความ

## การตรวจ

ทดสอบเนื้อหาที่มีข้อเท็จจริงนอกหัวข้อ, cache เปลี่ยนเมื่อเนื้อหาเปลี่ยน, script ไม่ทำงาน, redirect ไป host ภายนอกถูกปฏิเสธ, ขนาด/ชนิดเนื้อหา, cache ข้ามการสร้าง service ใหม่ทั้ง SQLite และ libSQL HTTP จริง รวมถึง cache อ่าน/เขียนล้มเหลว และข้อจำกัด concurrency ทดสอบ API แยกบัญชี/แหล่งข่าว รวมถึง logout หรือปิดแหล่งข่าวขณะกำลังอ่าน Playwright ตรวจ UI ทั้งสองธีมที่ 390/768/1440px พร้อมกรณีอ่านบางส่วน เว็บปิดการอ่าน และผลที่กลับมาหลัง logout
