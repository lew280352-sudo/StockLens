# สถานะและข้อจำกัดของ StockLens

[เกี่ยวกับแอป](ABOUT.md) · [คู่มือใช้งาน](USER_GUIDE.md) · [คู่มือทั้งหมด](README.md)

อัปเดต 14 พฤศจิกายน 2026 เว็บ [StockLens](https://stocklen-znwy.onrender.com/) ใช้งานผ่าน HTTPS แล้ว ใช้ Render Free + Turso และมี [Android 0.9.2 Beta](https://github.com/lew280352-sudo/StockLens/releases/tag/android-v0.9.2-beta.1) การตรวจด้วยบัญชีจำลองเป็นการตรวจการทำงาน ไม่ใช่การทดสอบความเข้าใจของผู้ใช้จริงหรือการรับรองความปลอดภัยจากภายนอก

## สิ่งที่ใช้งานได้และขอบเขต

| หัวข้อ | สถานะและข้อจำกัด |
| --- | --- |
| การติดตั้ง | Android มี signed APK และ PWA; Windows/macOS/Linux/Chromebook และ iPhone/iPad ใช้เว็บแอปตามเบราว์เซอร์ที่รองรับ ต้องใช้อินเทอร์เน็ต ดู [วิธีติดตั้ง](INSTALLATION.md) |
| บัญชีและรายการติดตาม | สมัคร เข้าสู่ระบบ รหัสกู้คืน ส่งออก ลบบัญชี และจัดการเซสชันอุปกรณ์ได้ รายการแยกตามบัญชี ไม่เก็บจำนวนหุ้นหรือต้นทุน |
| บริษัทและข่าว | รายชื่อบริษัทสหรัฐฯ 36 ตัว ข่าว RSS ตรงจาก Apple/Microsoft/NVIDIA/Netflix และข่าวการเงินผ่าน Finnhub เมื่อตั้งคีย์ ข่าวอาจไม่ครบหรือไม่มีข่าวใหม่ทุกวัน |
| แหล่งข่าวเพิ่มเติม | เพิ่มฟีด Federal Reserve ที่ตรวจสอบไว้ได้ URL อื่นที่ไม่ได้รองรับเป็นบุ๊กมาร์ก ยังไม่มีตัวอ่าน RSS สำหรับทุกเว็บไซต์ |
| การค้นหาบริษัท | รายการติดตามจำกัดบริษัทที่รองรับ การค้นผ่าน Finnhub ค้นนอกชุดนี้ได้ แต่ไม่ได้หมายความว่าจะเพิ่มเข้ารายการติดตามได้ทุกตัว |
| สรุปและถามบทความ | ใช้เนื้อหาสาธารณะของแหล่งที่อนุญาต มีแหล่งอ้างอิงและสถานะอ่านบางส่วน คำถามใช้บทความที่เลือกและใช้โควตาร่วมกับสรุป ไม่ใช่การค้นทุกเว็บ ดู [ขอบเขตบทความ](ARTICLE_SUMMARIES.md) |
| ค้นข่าวที่เกี่ยวข้อง | รวบรวมหัวข้อและลิงก์จากแหล่งที่เปิดไว้โดยไม่ใช้โมเดล จึงยังใช้ได้เมื่อ AI ไม่พร้อม ไม่มีการสร้างสรุปจำลองแทน |
| ค้นข่าวย้อนหลัง | เลือก 1/3/6 เดือนจาก Finnhub ใช้หัวข้อ/คำอธิบายและอาจไม่ครบตามโควตาผู้ให้บริการ แยกจากการอ่านเนื้อหาบทความ |
| AI | Groq ตรวจสรุปและตอบคำถามบริการจริงแล้ว Gemini ตรวจผ่าน fixtures การพร้อมใช้งานจริงขึ้นกับคีย์ โมเดลและโควตา AI อาจผิดหรือขาดบริบท |
| ราคาและการเปรียบเทียบ | Finnhub API และ TradingView มีสถานะเวลา/ข้อมูลล่าช้า เปรียบเทียบวันซื้อขายก่อนหน้า, 1 สัปดาห์, 1/3/6 เดือน และ 1 ปีได้ ข้อมูลวิดเจ็ตใช้แสดง ไม่ดึงไปคำนวณใน API/AI ดู [รายละเอียดราคา](PRICE_WIDGETS.md) |
| แนวโน้ม | มีกราฟและสัญญาณเทคนิค TradingView รายวัน/สัปดาห์/เดือน ผลทดสอบ Alpha Vantage แสดงตามข้อมูลและเงื่อนไขที่ผ่าน ยังไม่มีโมเดล AI ทำนายราคา และผลย้อนหลังไม่รับประกันอนาคต |
| ความครอบคลุมข้อมูล | ยังไม่มีทุกหลักทรัพย์ งบการเงินครบชุด FX ภาษี หรือการคำนวณกำไรขาดทุนพอร์ต ไม่ได้ตรวจข้อเท็จจริงข้ามสำนักหรือยืนยันข่าวคู่ค้าอัตโนมัติ |
| อีเมลและ Push | ยังไม่ได้ยืนยันการส่งถึงอุปกรณ์จริงครบ ไม่มีอีเมลสรุปข่าวรายวัน โฮสต์ Render ฟรีบล็อก SMTP ตาม profile ที่ใช้ จึงปิด email-login OTP ไว้; บัญชี Authenticator เดิมใช้ต่อได้เมื่อมีคีย์เดิม |
| โฮสต์ฟรี | อาจพักเมื่อไม่มีการใช้งาน เปิดครั้งแรกจึงช้า ระหว่างพักไม่มีรอบดึงข่าว/Push ข้อมูลบัญชีอยู่บน Turso ไม่ควรเก็บฐานหลักไว้บน filesystem ชั่วคราวของ Render |

## ข้อมูลส่วนตัวและการลบบัญชี

คำถามและข้อความข่าว/บทความที่เกี่ยวข้องส่งให้ผู้ให้บริการ AI ที่ตั้งไว้ ชื่อบัญชี อีเมล รหัสผ่าน และคีย์ไม่ได้รวมใน prompt บริการกราฟและลิงก์ต้นทางติดต่อผู้ให้บริการของตนเอง

การถอนแอปไม่ลบบัญชีบนเซิร์ฟเวอร์ ใช้เมนูลบบัญชีในแอป ข้อมูลในฐานใช้งานจะถูกลบตามขั้นตอน แต่สำเนาสำรองเก่าต้องจัดการแยกโดยผู้ดูแล

## สำหรับผู้ดูแล

คีย์ข่าว/AI, MFA และ VAPID อยู่ใน Environment ของเซิร์ฟเวอร์ ต้องเก็บคีย์ที่จำเป็นคู่กับ backup เมื่อต้องย้ายหรือกู้บริการ ส่วน Android ต้องสำรอง private signing key เดิมเพื่อออก APK อัปเดต

ดู [ตั้ง AI ออนไลน์](AI_ONLINE.md), [โฮสต์ฟรีและ backup](FREE_CLOUD.md), [ดูแลเซิร์ฟเวอร์](OPERATIONS.md) และ [การตรวจความปลอดภัยภายใน](SECURITY_REVIEW.md) การทดสอบในโปรเจกต์ไม่ใช่รายงาน audit จากผู้ตรวจอิสระ
