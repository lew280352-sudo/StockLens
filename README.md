## ติดตั้งบนอุปกรณ์ของคุณ

เปิด [StockLens](https://stocklen-znwy.onrender.com/) บนอุปกรณ์ที่ต้องการ แล้วเลือกวิธีด้านล่าง ใช้ผ่านเว็บได้ทันทีโดยไม่ต้องติดตั้ง

| อุปกรณ์ | วิธีติดตั้ง |
| --- | --- |
| **Android 8 ขึ้นไป** | [ดาวน์โหลด APK](https://github.com/lew280352-sudo/StockLens/releases/download/android-v0.9.2-beta.1/StockLens-0.9.2-beta.1.apk) → เปิดไฟล์ → อนุญาตการติดตั้งจากเบราว์เซอร์เมื่อระบบถาม → ติดตั้ง ต้องมี Chrome หรือเบราว์เซอร์ที่รองรับ |
| **Windows / PC** | เปิดเว็บด้วย Edge หรือ Chrome → กดไอคอนติดตั้งที่แถบที่อยู่ → **ติดตั้ง / Install** จากนั้นเปิด StockLens จากเมนู Start |
| **macOS** | Safari บน macOS 14 ขึ้นไป → **File → Add to Dock** หรือใช้ปุ่มติดตั้งใน Chrome |
| **iPhone / iPad** | เปิดเว็บใน Safari → **แชร์ → เพิ่มไปยังหน้าจอโฮม** → เปิด **Open as Web App** หากมี → **เพิ่ม** |
| **Linux / Chromebook** | เปิดเว็บด้วย Chrome → กดไอคอนติดตั้งที่แถบที่อยู่ หรือเมนู **Install page as app** → **Install** |

Windows, macOS และ Linux ใช้การติดตั้งเว็บเป็นแอป (PWA) ส่วน Android เลือกใช้ APK หรือ PWA ได้ [ดูขั้นตอนละเอียดและวิธีแก้เมื่อติดตั้งไม่ได้](docs/INSTALLATION.md)
